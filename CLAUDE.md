# studio-ai

What AI agents need to build Highrise worlds in Highrise Studio. The agent guide that Studio serves through its commands (`hr_guide`, `hr_examples_*`, and the script and UI templates) now ships with Studio: put new agent guidance there, not in this repository or the Rosie plugin.

This repository is public. Keep internal plans, unreleased projects and internal names out of its files and commit messages.

## Subprojects

- [guide/README.md](guide/README.md) - The retired agent guide, kept for the earlier Studio versions that download it: it tells their agents to update Studio.
- [rosie/CLAUDE.md](rosie/CLAUDE.md) - Rosie, the earlier Claude Code plugin for Highrise Studio, kept for its existing users.
